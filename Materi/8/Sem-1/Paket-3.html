Bab 3 Algoritma dan Pemrograman

Tujuannya adalah untuk merancang penyelesaian masalah yang melibatkan literasi numerasi dan bagaimana menuliskan sekumpulan instruksi dengan menggunakan kumpulan kosakata yang terbatas atau simbol dalam format pseudocode

A. Literasi Numerasi

Menyajikan informasi dalam bentuk grafik, tabel, dan bagan

bermanfaat untuk menyelesaikan masalah secara praktis dalam kehidupan sehari-hari, memprediksi sesuatu, membantu proses pengambilan keputusan

contoh pendekatan matematika dan literasi numerasi

  • peserta karya wisata = 40
  • kapasitas kendaraan = 12

1. dengan matematika

40 / 12 = 3,3

5 kebawah dibulatkan 0. 5 keatas dibulatkan keatas

maka dibutuhkan 3 kendaraan

2. literasi numerasi

sama seperti matematika

3 x 12 = 36 orang

sisa 4 orang tanpa kendaraan

maka butuh 3 kendaraan untuk 36 orang, dan 1 kendaraan untuk 4 orang

B. Eksplorasi lanjutan scratch

1. kode control, input, variable

control mengatur jalannya program, seperti perulangan dan kondisi

input digunakan untuk meminta masukan dari pengguna untuk dimasukkan dalam variable

variable adalah nama yang digunakan untuk menyimpan sebuah nilai

2. kode custom block

blok kode yang dapat dibuat sendiri dan disesuaikan fungsinya

C. Pengantar blockly games dan eksplorasi puzzle maze

custom block pada blockly adalah tools yang dapat membantu membuat program sederhana dengan menggunakan blok-blok, seperti scratch

blockly bisa diubah jadi bahasa pemrograman JavaScript, PHP, Python

D. Pengenalan Pemrograman Prosedural

menuliskan sebuah program komputer

  1. menerima input, disimpan dalam variable, mengambil isinya dengan menyebutkan nama variable
  2. mengeluarkan output dengan perintah "print", "write", "display" untuk menampilkan nilai variable
  3. melakukan perhitungan aritmatika dan logika [kali, bagi, tambah, kurang, modulus, and, or, not, >, <, =]

Program ganjil genap

  1. baca bilangan N
  2. hitung K = sisa pembagian N dengan 2
  3. bandingkan k dengan 0
  4. jika k = 0 maka genap, jika tidak berarti ganjil

Program loop 1+2+3+..+N

  1. Baca N
  2. Sum = 0; i = 0
  3. Ulangi Sum = Sum+i sampai i=N
  4. Print Sum

1. Variable

Variabel digunakan untuk menyimpan nilai

variabel harus memiliki nama dan berbeda dengan variabel yang lain

variabel harus mudah diingat

2. Percabangan

memeriksa nilai kebenaran melalui kondisi, dengan operasi perbandingan dan logika

  1. sama dengan → memeriksa kesamaan dua nilai
  2. tidak sama dengan → memeriksa perbedaan dua nilai
  3. kurang dari → memeriksa apakah nilai lebih kecil dari nilai lainnya
  4. lebih dari → memeriksa apakah nilai lebih besar dari nilai lainnya

3. Pengulangan

dalam komputer dikenal sebagai loop atau repetition
