2.1 Penjelasan

  • Pengolah Kata → Membuat dan mengolah dokumen → Word, Open Office Word, Google Docs
  • Pengolah Lembar Kerja → Lembar kerja pengolah data, Perhitungan data, Pengolah data statistik, Menampilkan diagram data → Microsoft Office, Open Office Spreadsheet, Google Sheets
  • Pembuat Presentasi → Membuat slide presentasi mudah, cepat, menarik → Microsoft PowerPoint, Open Office Presentation, Google Slides

rumus fungsi statistik excel:

  1. Sum
    Menjumlahkan data dalam list / range tertentu
  2. Average
    Mencari nilai rata-rata dalam list / range tertentu
  3. Count
    Menhitung banyak data dalam list / range tertentu
  4. Max
    Mencari nilai maximum / terbesar dalam list / range tertentu
  5. Min
    Mencari nilai minimum / terkecil dalam list / range tertentu

Integrasi konten antar aplikasi:

  1. Perintah Cut, Copy, Paste
    • a. Cut (Ctrl + X) memindahkan objek ke clipboard (penyimpanan sementara)
    • b. Copy (Ctrl + C) menyalin objek ke clipboard
    • c. Paste (Ctrl + V) memindahkan objek dari clipboard ke tujuan
  2. Konten pada aplikasi

    digunakan pada salah satu aplikasi yang otomatis membuka aplikasi lainnya

    contoh: Insert Chart pada Microsoft Word

  3. Object Linking dan Embedding (OLE)

    memungkinkan sebuah aplikasi terhubung dengan aplikasi lain, dengan fitur dan hasil.

    perubahan pada sumber mengakibatkan perubahan pada aplikasi lainnya

2.1.1 Integrasi Word dan Excel

langkahnya:

  1. Buka Microsoft Word
  2. Insert → Chart → pilih jenis chart → OK
  3. Excel otomatis terbuka, isi dengan data, tutup kembali
  4. ubah judul grafik dan diagram dengan double click chart title

2.1.2 Integrasi PowerPoint

langkahnya:

  1. Buka Microsoft PowerPoint
  2. Insert → Table → Excel Spreadsheet → membuka worksheet otomatis
  3. Table dan fitur excel dapat langsung digunakan, hasilnya otomatis tampil
  4. update data dengan double click tabel

2.1.3 Membuat Diagram pada PowerPoint dengan Excel

langkahnya:

  1. Buka Microsoft PowerPoint
  2. Insert → Chart → pilih jenis diagram → OK
  3. diagram dan spreadsheet excel otomatis muncul
  4. tutup worksheet excel, ubah judul dengan double click Chart Title

2.1.4 Object Linking & Embedding (OLE) pada Excel ke Word

Bisa dilakukan dengan copy paste, tapi datanya akan statis

langkahnya:

  1. Buka Microsoft Excel
  2. Buat tabel
  3. Block Select tabel, lalu copy
  4. Buka Microsoft Word
  5. Paste Options → Link & Keep Source Formatting atau Link & Use Destination Style
  6. Perubahan pada excel akan diterapkan otomatis ke word

2.1.5 Object Linking & Embedding (OLE) pada Excel ke PowerPoint

  1. Buka Microsoft Excel
  2. Buat tabel
  3. Save
  4. Buka PowerPoint
  5. Gunakan menu Insert Object
  6. Pilih file Excel → centang opsi Link → OK
  7. Perubahan pada excel akan diterapkan otomatis ke powerpoint

2.1.6 Pemrosesan Dokumen dengan Perangkat Lunak Perkantoran

A. Mail Merge

fitur yang digunakan untuk menghasilkan surat, amplop, undangan, dll secara berulang dengan beberapa komponen yang berbeda

Langkah:

  1. Buka Excel
  2. buat tabel data yang diinginkan
  3. simpan file excel
  4. buka word
  5. buat dokumen
  6. Mailing → Select recipients → Use an existing list
  7. cari file excel yang dibuat
  8. open → pilih sheet → OK
  9. Letakkan cursor pada kanan teks
  10. Insert Merge Field → pilih hubungan
  11. ulangi langkah 9 - 10 untuk bagian lain
  12. klik preview result untuk melihat hasil
