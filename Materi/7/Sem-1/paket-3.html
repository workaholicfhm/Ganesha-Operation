TEKNOLOGI INFORMASI DAN TELEKOMUNIKASI

3.1 Pengenalan Graphical User Interface (GUI)

adalah bentuk antarmuka pengguna dengan menggunakan ikon dan elemen grafis sebagai pengganti perintah berbasis teks atau CLI (Command Line Interface)

3.2 Perangkat Keras dan Perangkat Lunak

Perangkat Keras Adalah perangkat komputer yang memiliki bentuk nyata , dapat disentuh, dipindahkan, dapat berguna sebagai input, output, processor, storage

  1. perangkat masukan digunakan untuk memasukkan data atau perintah ke komputer

    contohnya: Mic, Mouse, Joystick, Headphone, Keyboard, dsb

  2. Perangkat pemroses digunakan untuk memproses data atau perintah yang diterima

    contohnya: Random Access Memory (RAM), Read Only Memory (ROM), Central Processing Unit (CPU)

  3. Perangkat keluaran digunakan untuk menyajikan informasi dari komputer

    contohnya: Monitor, Printer, dsb

Perangkat Lunak adalah kumpulan instruksi dan data yang dikerjakan oleh komputer

menjadi penghubung antara pengguna dengan komputer

terdiri dari Program, Library, dsb

3.3 Folder dan File

Folder atau Directory adalah tempat penyimpanan elektronis yang berisi file atau folder lain

File adalah unit penyimpanan dalam komputer yang dapat dibaca atau ditulis

File hanya dapat ditulis dan dibaca oleh program/aplikasi tertentu saja

contoh media penyimpanannya adalah hard disk, memori, flash drive, dsb

1. ekstensi file

nama pendek setelah tanda titik di akhir nama file

  • bunga.jpg -> file image
  • surat.doc -> file Microsoft Word
  • presentasi.ppt -> file dari Microsoft PowerPoint
  • dsb

2. pengelolaan folder

pengelolaan folder dan file adalah fitur yang ada pada sistem operasi yang biasa disebut file explorer, atau file management system

3. pengelolaan file dengan sistem operasi Microsoft Windows

file explorer berfungsi untuk membuat, menyalin, menghapus, memindahkan, mencari file dan folder

3.4 Aplikasi Perkantoran

adalah aplikasi yang digunakan untuk meningkatkan produktivitas

  1. aplikasi pengolah kata

    mengelola dokumen yang terdiri atas teks, halaman, paragraf, kata, tanda baca, dll

    contohnya: Microsoft Word, dengan format penyimpanan doc, docx, dll

  2. aplikasi pengolah lembar kerja

    mengelola kumpulan lembar kerja (worksheet) yang di dalamnya dapat berisi angka, teks, formula (rumus), dll

    contohnya: Microsoft Excel, dengan format penyimpanan xls, xlsx, dll

  3. aplikasi presentasi

    digunakan untuk mengelola sekumpulan slides untuk mempresentasikan sesuatu, berisi teks, gambar, dll

    contohnya: Microsoft PowerPoint, dengan format penyimpanan ppt, pptx, dll
