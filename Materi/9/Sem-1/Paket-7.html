Paket I Analisis Data

1.1 Pencarian Data

ketika data ditemukan (True), tidak ditemukan (False)

  1. fungsi lookup
  2. fungsi reference

A. Fungsi Lookup

artinya mendapat data tentang sesuatu

  1. VLOOKUP dipakai jika range data tersusun vertikal
  2. HLOOKUP dipakai jika range data tersusun horizontal

1. penggunaan VLOOKUP

formula

=vlookup(yg_dicari, array_data, no_kolom_tampil, [range])

keterangan:

yg_dicari = nilai yang dicari

array_data = tabel berisi data yang dicari

no_kolom_tampil = nomor kolom yg diambil datanya

range TRUE/FALSE = opsional

  • a. TRUE = jika ingin hasil yang mendekati nilai
  • b. FALSE = jika ingin hasil yang sama persis

2. penggunaan HLOOKUP

=hlookup(yg_dicari, array_data, no_baris_tampil, [range])

no_baris_tampil = nomor baris yg diambil datanya

B. Fungsi Reference

mengacu pada sesuatu

  1. match
  2. index
  3. choose

1. Penggunaan Fungsi Match

mengembalikan posisi dari suatu nilai

formula

=match(yg_dicari, array_data, [match])

match = bernilai -1, 0, dan 1

  • 1 untuk < nilai
  • 0 nilai yang sama persis
  • -1 untuk > nilai

2. penggunaan fungsi index

mengembalikan nilai dari range dua dimensi

formula

=index(array_data, nomor_baris, [nomor_kolom])

3. penggunaan fungsi choose

mengembalikan suatu nilai dari sederet nilai

formula

=choose(index_data, nilai, [nilai2], [nilaiN])

index_data = bilangan yang menunjukkan posisi

nilai, .., nilaiN = bisa berupa angka, teks, referensi sel

1.2 Visualisasi data

A. Tujuan visualisasi data

  1. memudahkan dalam memahami makna data
  2. untuk melakukan prediksi terhadap nilai data (line atau column)

dalam membuat chart:

  1. tentukan jenis chart
  2. jika untuk beberapa kolom data tuliskan legend
  3. berikan judul, label sumbu, label bermakna

B. Jenis Chart

INSERT → CHART → Pilih Chart

Column Chart
membandingkan nilai dari beberapa kelompok data memakai batang vertikal

Line Chart
menampilkan tren data dalam selang waktu

Bar Chart
versi horizontal dari column chart

Pie Chart
Menampilkan kontribusi dari tiap nilai terhadap nilai keseluruhan

1.3 Peringkasan Data

agar dapat melihat gambaran umum dari data

  1. fungsi kalkulasi data berkondisi, SUMIFS, COUNTIFS
  2. pivot table
  3. tables otomatis dari perangkat pengolah data

A. Fungsi Sumifs

menghitung jumlah isi nilai dari kumpulan data berdasarkan kondisi tertentu

=sumifs(data_nilai, data_syarat, kondisi, ..)

data_nilai = range data yang akan dijumlah nilainya

data_syarat = range data yang menyimpan kondisi yang ditentukan

kondisi = nilai kondisi yang harus dipenuhi

B. fungsi countifs

menghitung banyaknya data berdasarkan kondisi tertentu

=countifs(data_syarat, kondisi, [data_syarat2, kondisi2, ...])
